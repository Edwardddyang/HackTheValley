# Apartment Building Evaluations (RentSafeTO)

Download from: https://open.toronto.ca/dataset/apartment-building-evaluation/

Put these file(s) in this folder, unchanged:

- 'Apartment Building Evaluations 2023 - current.csv' (downloads as apartment-building-evaluations-2023-current.csv)
- Optional, older evaluations: 'Pre-2023 Apartment Building Evaluations.csv' (downloads as pre-2023-apartment-building-evaluations.csv)

Then run `uv run bb check rentsafe` from the etl/ folder.
