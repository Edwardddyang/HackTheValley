# Neighbourhood Profiles, 2021 Census (158 model)

Download from: https://open.toronto.ca/dataset/neighbourhood-profiles/

Put these file(s) in this folder, unchanged:

- 'neighbourhood-profiles-2021-158-model' XLSX (downloads as nbhd_2021_census_profile_full_158model.xlsx)

Then run `uv run bb check neighbourhood_profiles` from the etl/ folder.
