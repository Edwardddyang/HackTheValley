# Neighbourhoods (158 model) boundaries

Download from: https://open.toronto.ca/dataset/neighbourhoods/

Put these file(s) in this folder, unchanged:

- 'Neighbourhoods - 4326.geojson' (downloads as neighbourhoods-4326.geojson; not the 'historical 140' file)

Then run `uv run bb check neighbourhoods` from the etl/ folder.
