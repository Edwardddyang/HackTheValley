# Address Points (Municipal) - Toronto One Address Repository

Download from: https://open.toronto.ca/dataset/address-points-municipal-toronto-one-address-repository/

Put these file(s) in this folder, unchanged:

- 'Address Points - 4326.csv' (downloads as address-points-4326.csv, ~180 MB)

Then run `uv run bb check address_points` from the etl/ folder.
